## 🚀 Features

### 🛡️ Ironclad Administration & Moderation
Keep your community safe, clean, and organized with lightning-fast moderation actions.
* **Auto-Moderation:** Automatically filters slurs, mass mentions, and spam invites.
* **Easy Punishments:** Ban, kick, mute, or warn users instantly via simple commands.
* **Timed Mutes/Bans:** Automatically unban or unmute users after a set duration.
* **Server Logging:** Keep track of deleted messages, edited messages, and member leaves/joins in dedicated channels.

### 🎉 Engagement & Entertainment
Give your community members a reason to stay active and have fun together.
* **Music Processing:** Allows you to make the bot join voicechat and play music for you and your friends.
* **Jokingly can Insult other members** Pull the freshest memes straight from Reddit or generate custom text-on-image templates.
* **Interactive Triggers:** Image processing, Insulting Jokes, and Jumpscare Gifs.

## 🎮 Command Overview

| Command | Category | Description |
| :--- | :--- | :--- |
| `/ban @user [reason]` | Moderation | Bans a user from the server permanently. |
| `/unban @user` | Moderation | Unbans a user.|
| `/clear [amount]` | Moderation | Deletes a bulk amount of messages from a channel. |
| `/kick` | Moderation | Kicks a member |
| `/mute` |Moderation | Mutes a member |
| `/unmute` | Moderation | Unmutes a member. |
| `/play` | Entertainment | Enables to bot to join voicechat and play tunes of your liking! |
| `/userinfo` | Information | Allows you to view the account creation and etc of a user. |
| `/8bit` | Entertainment | Sends a random 8-bit style image. |
| `/8ball` | Entertainment | Ask the magic 8-ball a question. |

*These are not all of the commands that can be used*
*--------------------------------------------------*
*Type `/commands` in your server for a full, interactive list of all available commands.*
